# User Authentication & Authorization

Standalone Node demo for login, signup, OTP verification, and role-based authorization rules.

## Stack

- Node.js
- Express 4
- Zod validation
- ESLint 9

## Scripts

- `npm install`
- `npm run dev`
- `npm start`
- `npm run lint`

## Boilerplate Focus

- Consistent API response shape
- Validation at the route boundary
- Clear error normalization and route organization
